IMPORTANT:
The app cannot be installed while opened from ChatGPT's media/file viewer.

For Android installation:
1. Upload all files in this folder to an HTTPS static host (GitHub Pages, Netlify, Cloudflare Pages, etc.).
2. Open the HTTPS address in Chrome on Android.
3. Chrome menu (⋮) > Install app / Add to Home screen.

The UI and analysis work immediately in a browser. PWA installation requires HTTPS and a normal web origin.
